Icons in this folder
====================

The .svg files here are Lucide icons (https://lucide.dev, lucide-static 0.460.0), bundled
so the frame can draw its core icons with no network. Any other Lucide icon is downloaded
on demand (inky_icons_package.py, pinned to the same version).

skate.svg, gymnastics.svg and soccer.svg have no Lucide equivalent and were drawn for this
project in the same style (24x24, stroke 2, round caps and joins).

The .png files are older icons, used only for names that have no SVG anywhere.
